# Adam Abdelsalam Portfolio

A responsive personal portfolio website for Adam Abdelsalam, built with semantic HTML, CSS, and vanilla JavaScript.

## Features

- Responsive layout for phone, tablet, and desktop
- Modern editorial portfolio design
- About, skills, projects, achievements, leadership, and learning sections
- Links to Adam's GitHub, Figma prototype, and FlutterFlow project
- Add This Work form with browser-local project persistence using `localStorage`
- Accessible navigation, labels, external-link handling, and reduced dependency footprint

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

The project form stores new projects in the visitor's browser. Permanent, shared submissions would require a backend or database.
